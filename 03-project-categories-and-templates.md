# Project Categories and Templates

Your work is grouped into **six categories**. Each category has:

1. A **card template** (what shows on the Projects grid and the Home page)
2. A **case-study template** (what shows on the project page)
3. The **metrics that matter** for that type of work

Fill in the templates for each of your 5+ projects and send them back. Anything you don't have yet can be left blank; I'll use placeholders and we'll swap them later.

---

## The six categories

| # | Category | Typical clients | Why it's on the list |
|---|----------|----------------|----------------------|
| 1 | **E-commerce** | Shops, brands, product sellers | Shows you can build stores that sell |
| 2 | **Landing Pages** | Product or offer launches | Fast, focused, conversion-first pages |
| 3 | **Sales Funnels** | Coaches, course sellers, lead-gen businesses | Pages plus automation and follow-up |
| 4 | **Business Websites** | Companies, firms, agencies | Credibility and lead generation |
| 5 | **Web Applications** | Startups, internal tools, platforms | Your highest-value, development-heavy work |
| 6 | **CRM and Automation (GHL)** | Businesses needing systems | Fits your GHL setup and sets you apart |

If one of these doesn't match your work, tell me and we'll change it. Possible additions: Redesigns, Booking systems, Membership sites.

## Template A: Project card (used for every category)

Copy this block once per project.

```
Project name:
Category: (one of the six above)
One-line description: (what it does and for whom, max 90 characters)
Headline result: (one number if you have it, e.g. "+212% conversion", "3-day build", "500+ orders")
Live link:
Cover image: (file name, 16:10 ratio if possible)
Tags: (up to 3, e.g. Shopify, Paystack, WordPress)
Featured on Home? (yes/no)
```

## Template C: Category-specific fields

### 1. E-commerce
Metrics that matter: sales, orders, conversion rate, average order value, speed.

```
Platform: (Shopify / WooCommerce / custom / other)
Number of products:
Payment methods: (Paystack, Flutterwave, Stripe, pay on delivery…)
Delivery / logistics setup:
Key store features: (filters, cart, wishlist, coupons…)
Result: (orders, revenue growth, conversion rate, page speed)
Before / after: (what changed)
```

### 2. Landing Pages
Metrics that matter: conversion rate, load speed, leads, cost per lead.

```
Offer / product:
Goal of the page: (sell, collect leads, book calls)
Traffic source: (Facebook ads, Google, WhatsApp, organic)
Sections used: (hero, proof, offer, FAQ, form…)
Page speed: (score or load time)
Result: (conversion rate, leads, sales)
```

### 3. Sales Funnels
Metrics that matter: leads, cost per lead, conversion between steps, revenue.

```
Funnel type: (lead gen, webinar, product sale, booking)
Steps: (e.g. Landing → Form → Thank-you → Upsell)
Platform: (GHL / ClickFunnels / other)
Automation built: (SMS, email, WhatsApp follow-up, pipelines)
Result: (leads, booked calls, sales, cost per lead)
Funnel diagram: (screenshot or sketch of the steps)
```

### 4. Business Websites
Metrics that matter: enquiries, traffic, speed, SEO position.

```
Industry:
Pages built: (Home, About, Services, Contact…)
Special features: (booking, blog, multi-language, WhatsApp chat)
SEO / speed work done:
Result: (enquiries per month, traffic, ranking)
```

### 5. Web Applications
Metrics that matter: users, features shipped, uptime, time saved.

```
What the app does:
Who uses it:
Core features: (auth, dashboard, payments, admin panel…)
Stack: (frontend, backend, database, hosting)
Hard problem solved: (one technical challenge and how you solved it)
Result: (users, time saved, revenue, uptime)
Demo link or login: (a demo account if possible; never send real passwords here)
```

### 6. CRM and Automation (GHL)
Metrics that matter: hours saved, leads handled, response time, conversion.

```
Business type:
Problem before: (manual follow-up, missed leads…)
What you automated: (pipelines, workflows, reminders, reviews, chatbots)
Integrations: (WhatsApp, Stripe, calendar, forms…)
Result: (hours saved per week, response time, show-up rate, sales)
Workflow diagram: (screenshot)
```

## How these map to the site

- **Projects page:** filter chips for All plus the six categories; each card uses Template A.
- **Project page:** Template B at the top, then the matching Template C section, then screenshots and a "Start a Project" button.
- **Home page:** 3 to 4 cards marked "Featured on Home".
- **Start a Project form:** step 3 offers the same six categories.
